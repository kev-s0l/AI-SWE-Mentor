In LLM chat APIs and prompt engineering, conversation structures are organized into three primary message roles:

- System: Sets the foundational rules, persona, tone, safety boundaries, and global instructions for how the AI should behave. It acts as the "backstage note" guiding every turn that follows.

- User: Represents the active input, questions, tasks, or data submitted by the human user for the current turn.

- Assistant: Represents the model's generated response (or historical responses saved in the conversation memory to maintain multi-turn context)
